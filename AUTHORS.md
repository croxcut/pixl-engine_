# Pixl Engine author

Pixl Engine is my year's long hobby project, experementing from a simple software 2D renderer to a full 3D rendering engine. 

It's been almost 2 years and little progress had beeng done since im busy with completing my academic duties.

For now only OpenGL 4.1 is supported for rendering backend, Vulkan support will follow and by then OpenGL will be a fallback layer for the Vulkan renderer.

My Current plan is to make the entire engine modular and contains micro servers for handling rendering from audio to physics.
